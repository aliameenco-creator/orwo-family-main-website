# ORWO Family WordPress theme

Custom theme for **ORWO Family** (orwo.family), rebuilt from the archived Strikingly site.

## Install

1. WordPress → Appearance → Themes → Add New → Upload Theme → choose `orwo-family.zip` → Install → Activate.
2. Click **Complete ORWO Family setup** in the yellow notice (turns on pretty permalinks so `/contact` and `/pages/cookie-policy` work, and sets the site title to "ORWO Family").
3. Send one real test enquiry from `/contact` and confirm it arrives at hello@orwo.family. If it does not arrive, install an SMTP plugin; the enquiry is still saved under **Enquiries** in wp-admin.

No pages or imports are needed: the landing page, contact page and cookie policy are part of the theme.

## Updates

Appearance → **ORWO Family Updates** checks the latest stable `vX.Y.Z` GitHub release of this repository and installs its verified `orwo-family.zip` asset.

## What lives where

| Thing | Where |
| --- | --- |
| Landing page, header, footer, cookie policy | `parts/*.html` (generated from the archive) |
| Contact form definition | `parts/contact-form.json` |
| SEO titles/descriptions | `parts/seo.json` |
| Images, logo, favicon, fonts | `assets/` |
| Enquiries | wp-admin → Enquiries (database, never in Git) |

Layouts are generated by `tools/build_orwo_family_theme.py` in the migration workspace; edit the generator, not the generated HTML.
